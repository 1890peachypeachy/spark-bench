# Where the frozen inputs come from

| input | provenance | frozen how |
|---|---|---|
| `mmlu200.jsonl` | copied byte-for-byte from `deepseek-v41-tensorfold-spark/bench/data/mmlu200.jsonl` (the slice the TensorFold campaign scored MMLU-200 with: kit baseline 87.5 %, TensorFold 87.5 %) | sha256 `9afacd0317bd759dd7de09583e2cd5ac79d49b02506acc052421489104f4c4d6` |
| `math.jsonl` | public **GSM8K** test split, rows 0–29 (`openai/gsm8k`, `main`, fetched once from the HuggingFace datasets-server); the expected value is the `#### N` number from the reference answer | committed; the fetch is a one-time build step in `mkfixtures.py` |
| `if.jsonl`, `json_tasks.json`, `tool_tasks.json`, `coding.json`, `longctx.json`, `summary.json` | written for this suite; generated deterministically by `bench/mkfixtures.py` (explicit seed `20261015`, stdlib only) | committed + regenerated by the same seed |

None of these inputs is personal data. The synthetic fixtures use invented topics, invented keys and
invented values.

**Frozen means frozen.** To change an input, change the generator, rebuild, and say so in the commit — the
whole point is that two models run against byte-identical prompts.

Scoring is deterministic and offline in every area (letter match, numeric match, a programmatic checker per
instruction-following item, a client-side JSON-Schema validator, tool-call schema validation, hidden stdlib
`unittest` files, exact passkey match, exact planted-fact match). No LLM judge is used by `qbench`, so no
model-family bias and no judge cost.
