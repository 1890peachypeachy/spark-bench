Short prompts (tok/s)

Same prompt token IDs on both servers, 256 tokens. Copy-edit gains most: TensorFold also drafts from text it can copy.

Where prompt reading goes. Each 2,048-token chunk takes about 1.2 s: 0.73 s of compute and 0.40 s of exchanges between the four Sparks, run back to back. Overlapping the two is the next change; it would put prompt reading near SGLang's.

The fine print

  • Different weight files. TensorFold runs the 2.9-bit EXL3 copy of the uncensored model (about 200 GB); SGLang runs the 8-bit FP8/FP4 copy. Fewer bytes per token is most of the speed. Same uncensoring team and method.
  • TensorFold's expert pruning is on (production default, slightly lossy: top-1 agreement 0.9944 vs 0.9961 unpruned in jayleaton's gates). Turning it off costs about 5%.
  • Speculative decoding is exact on TensorFold: drafted replies equal one-token decoding. All gates passed on the live server, including the forced tool call SGLang failed.
  • One TensorFold boot; SGLang rows are its published EP2 sweep from 2026-10-02.
