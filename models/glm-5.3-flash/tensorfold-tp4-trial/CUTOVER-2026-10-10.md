## Key gotchas hit (record for next time)
1. First stop attempt ran FROM spark3 and ssh'd to node aliases that only exist in the MAC's
   ~/.ssh/config → docker stop silently did nothing; containers kept running + port held.
   RUN CUTOVER ALL COMMANDS FROM THE MAC (each node via its own alias), not from spark3.
2. NFS sub-path export is a container (dsv41-nfs), not `/etc/exports` on the host. The exporter
   serves `/var/tmp/models` as pseudo-root `/`. Put/cache model trees under a subdir of
   `/var/tmp/models` and set `NFS_PATH` to that pseudo-root subpath (for Ablit: `/glm53-hf`).
3. Worker Docker volumes cache the NFS device. If `NFS_PATH` changes, remove stale worker volumes
   first: `docker volume rm glm53-hf` on spark1/spark2/spark4, then restart the lane so
   `prepare.sh` recreates `device=:/glm53-hf`.
4. `WORKER_WEIGHTS=copy` is the wrong fix for a missing NFS view: it triggers `rsync` of the
   Ablit snapshot to each worker. Keep all three worker modes at `nfs` and fix the export path.
5. The 5-query-no-target-truncation: N/A here (serving, not eval).
